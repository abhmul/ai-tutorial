# AGENTS.md

Writing constraints for this repo. `ai-tools-guide.md` (detailed) and
`ai-tools-onepager.md` (summary) cover the same material; the README links both.

- Audience: newcomers with no AI experience. Plain language; define terms.
- Tone: neutral and factual. No superlatives, hype, slogans, or emoji.
- Capability claims must trace to official documentation.
- Cautionary claims must cite a primary or peer-reviewed source. Existing DOIs,
  arXiv IDs, and figures were fact-checked — verify before changing them.
- Keep the guide and one-pager in sync: same claims, same sources.
- Describe model tiers generically (most-capable / balanced / fast); do not
  hard-code version names.
